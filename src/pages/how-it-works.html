Setup guide

How WaBridge works — and how to set it up on Windows

Two small programs run side by side on your computer: the WaBridge workspace you see, and an open-source WhatsApp engine that keeps your linked numbers online. Setting both up takes about fifteen minutes.

Architecture

What happens when a customer messages you

Messages travel from WhatsApp to the engine, which passes them to WaBridge with a signature so nothing can be faked on the way.

Before you start

What you need

A normal office laptop is enough for one or two numbers. Keep it plugged in and set to not sleep while WaBridge is running.

Windows 10 or 11 (64-bit)macOS and Linux work too.

Docker Desktop with WSL 2Free for individuals and small businesses — check Docker's licence terms for larger companies.

8 GB RAM recommendedEach linked number uses roughly 300–500 MB.

A dedicated WhatsApp numberOn a phone with WhatsApp or WhatsApp Business. Avoid your main personal number.

Installation

Install WaBridge in six steps

  1. Install Docker Desktop

    Download it from docker.com, keep the default WSL 2 option, restart if asked, and wait until it shows “Engine running”.

  2. Unzip WaBridge

    Extract the zip somewhere simple, such as C:\WaBridge. Avoid OneDrive-synced folders.

  3. Double-click Start WaBridge.bat

    It creates fresh secret keys, downloads the engine (about 1 GB, first time only) and opens your browser.

  4. Create your admin login

    Enter your business name, your name, e-mail and a strong password. Teammates can be added later.

  5. Link your number

    WhatsApp numbers → Add number. On the phone: Linked devices → Link a device, then scan the QR.

  6. Turn on auto-replies

    Automations & AI → Add starter rules. Message the number “price” from another phone and watch the reply arrive.

Prefer the command line?

From the WaBridge folder in PowerShell:

powershell -ExecutionPolicy Bypass -File windows\setup.ps1
powershell -ExecutionPolicy Bypass -File windows\manage.ps1 logs
powershell -ExecutionPolicy Bypass -File windows\manage.ps1 backup

Check that everything works

  • The top bar shows Engine online and Live
  • Your number's card turns Connected
  • A message sent to the number appears in the Inbox instantly
  • manage.ps1 test runs 22 automatic checks
Data & security

Where your data lives

Chats, contacts, media and logs are stored in two Docker volumes on your own computer. Nothing is sent to a WaBridge server — there isn't one.

  • The dashboard is reachable only from your computer unless you change it
  • Passwords are scrypt-hashed; sessions use HTTP-only cookies
  • Every event between the engine and WaBridge carries an HMAC signature
  • One-command backups to a folder you choose

Treat backups like passwords: they contain your WhatsApp login.

Going online safely

Need to open WaBridge from outside the office, or receive Meta webhooks? Put it behind HTTPS with a tunnel instead of opening ports on your router:

winget install Cloudflare.cloudflared
cloudflared tunnel --url http://localhost:8080

For a permanent address, use a named tunnel with an access policy, and set COOKIE_SECURE=true.

Optional

Connecting the official Meta Cloud API

The QR-linked channel needs no Meta setup. If you also want approved-template marketing at scale, you will need these from your Meta Business account:

  • Phone Number ID and WhatsApp Business Account (WABA) ID from WhatsApp Manager → API setup
  • A permanent access token from a System User with WhatsApp permissions
  • Your app's App secret (to verify webhooks) and the verify token WaBridge generates
  • A public HTTPS address for the webhook, e.g. through a tunnel

A Business ID alone is not enough — the number must also be registered on the Cloud API.

Setup questions

The QR code never appears. What should I check?

The first start can take a couple of minutes. Make sure Docker Desktop has at least 2 GB of memory, then press Restart on the number's card.

My phone asks me to create a passkey and linking never finishes.

That is a restriction WhatsApp applies to some accounts, and no linked-device tool can complete it today. Try a different number, and avoid reserving a WhatsApp username on the number you automate.

What happens if my laptop sleeps or restarts?

Messages wait on WhatsApp's side while the laptop is off. When Docker starts again, numbers reconnect automatically and new messages flow into the inbox.

How do I move WaBridge to a server later?

Run the backup command, copy the backup files and the WaBridge folder to the server, and start it with the same docker compose command. Linux servers with 2 GB of RAM or more work well.
